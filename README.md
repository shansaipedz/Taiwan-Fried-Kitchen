🍗 Taiwan Fried Kitchen (TFK) System

A centralized Point of Sale (POS) and Inventory Tracking System designed to streamline restaurant operations for Taiwan Fried Kitchen.

📌 Overview

The TFK System integrates order processing, sales tracking, and inventory management into a single platform. It replaces manual workflows with a more efficient and organized system, improving accuracy and operational flow.

⚙️ Key Features
🧾 Point of Sale (POS)
Create and manage customer orders
Apply discounts (e.g., Senior Citizen)
Process payments and record transactions in real-time
📦 Inventory Management
Manual stock updates and deductions
End-of-Day (EOD) inventory audit
Structured tracking to minimize discrepancies
📊 Reports & Analytics
Sales reports
Inventory audit reports
Purchase expenses
Net profit overview
👥 Role-Based Access Control
Cashier: POS, inventory updates, view sales reports
Manager: Full system access (user management, menu updates, reports, approvals)
🚀 Purpose

To reduce manual errors, improve transaction accuracy, and provide a scalable and efficient system tailored to the operational needs of Taiwan Fried Kitchen.

🛠️ Tech Stack

Frontend: Next.js / React
Backend: Node.js
Database: Supabase
Authentication: Supabase Auth
